レンタルサーバー設定ガイド

レンタルサーバー（XServer, さくら, cPanel等）の管理画面でCronを設定する場合は、以下のいずれかの方法を利用してください。

方法1: サーバー管理画面のCron設定（推奨）

サーバーパネルの「CRON設定」に以下のコマンドをコピー＆ペーストしてください：

0 9 * * * cd /path/to/project && python AutoTicket.py

方法2: Web Cron / 外部トリガーURL

cron-job.org や サーバーのWebCron機能から定期実行を呼ぶURL：

http://.../api/cron/run?token=...
